# 驾驶员闭眼头像

使用内置 image_gen 工具分别生成，未使用 CLI。透明 PNG 保留原始字节，运行时只读取 alpha 蒙版并按驾驶员着色；生成图像为 1254×1254。

最终素材：`asuka-avatar-closed-eyes.png`、`rei-avatar-closed-eyes.png`。用户提供的两段 MP3 原字节复制为 `asuka-voice-boot.mp3`、`rei-voice-boot.mp3`，没有生成或模仿配音。
