## 改动与保留

- 高度场、Marching Squares 和二次曲线计算移至同源 Worker；最多一项计算在途，保留 24 层等高线、20fps 更新上限和相同路径结果。不支持时使用相同函数回退。
- 启动开场期间预解码两套头像和半身图；按下头像时准备启动音源，放手后复用。
- 拖动尺寸读取集中在开始时，位置更新不再反复读写布局；角色文本和进度时码仅在内容变化时写入。
- PNG、MP3、原始 SVG 内容不变，大媒体从 data URI 改为内容摘要 URL，浏览器可以缓存与按需读取。
- 后台与减少动态效果停止等高线调度，卸载／重播终止线程，不累积旧计算任务。

四个固定时间点的 24 条路径与整理前的摘要一致，原始媒体摘要、GIF 压缩帧和语音真实播放结束时序另有独立回归。

## 重现与范围

```sh
npm run perf:boot -- --output=/tmp/eva-boot-performance.json
```

性能采样使用模拟宿主会话与音频时钟，以分离拖放处理和持续等高线计算；完整回归另外解码原始 MP3 并等待真实播放完成。整理前使用内嵌资源的文件测试台，整理后使用与运行时相同的 HTTP 资源路由，资源传输方式也是本次优化的一部分。

以上为本机一次对照测试，受浏览器、机器负载和视口影响；requestAnimationFrame 是下一次呈现机会，不等于显示器实际像素呈现延迟。该测试不测量 DSH 全部会话负载，也不能保证所有设备持续 60fps。实际 DSH 验收用于确认流程、画面和声音可用，不将隔离测试数值当成宿主实测。
